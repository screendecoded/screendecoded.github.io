# TV Viewing angle and distance calculator

### Features

* Selection of desired screen size
* Slider for the viewing distance
* Visualization of seating position to the screen and what is the ideal distance for selected screen size (the ideal disatances to screen size are declared later in this document). It needs to have a perspective view and a top view. This interactively changes when use picks a different screen size or adjust the distance slider.
* User toggleable units for metric and imperial for distance slider. Screen size is inches only, because that's what everybody uses for screen sizes.

### Ideal viewing angle

The ideal viewing angle is 46 degrees. Meaning the ideal distance for 65 inch TV is 1.70 meters or 5.6 feet.

* 48" = 1.24m
* 55" = 1.46m
* 65" = 1.70m
* 75" = 1.96m
* 77" = 2.03m
* 83" = 2.18m
* 85" = 2.24m
* 98" = 2.54m
* 100" = 2.62m
* 115" = 3.00m
